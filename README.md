# webJakaDua
web jaka adalah sebuah game web open source yang dapat di jelajahi dengan keseruannya.
seperti berbelanja, memenuhi isi bar status, bahkan hingga bisa menikah. di game ini anda bisa melakukan
style pakaian untuk player anda.

# Teknologi
-HTML
-CSS
-JavaScript

# Cara Menjalankannya
buka file index.html langsung di browser anda baik di mobile atau pc.
